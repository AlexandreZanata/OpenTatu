# Recipes

Step-by-step procedures for common changes. Follow them in order; each ends with
`cargo xtask check`. If no recipe fits, read [../WORKFLOW.md](../WORKFLOW.md) and consider
writing one.

| Add a table or column | [add-migration.md](add-migration.md) |
| Add a dashboard page | [add-dashboard-page.md](add-dashboard-page.md) |
| Add a reusable UI component | [add-ui-component.md](add-ui-component.md) |
| Add a scanner | [add-scanner.md](add-scanner.md) |
| Change a prompt | [change-prompt.md](change-prompt.md) |

| Add a crate | [add-crate.md](add-crate.md) |
| Finish a roadmap phase | [finish-phase.md](finish-phase.md) |
